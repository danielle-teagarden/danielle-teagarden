# Danielle M. Teagarden

Writer, lawyer, dreamer, and doer.

I'm an Indiana lawyer who builds free tools and resources that make Indiana law easier to find, read, and understand. My website is [danielleteagarden.com](https://danielleteagarden.com).

## What I'm working on

- [Indiana Code MCP](https://mcp.openindianalaw.org): a prototype that lets AI tools read unofficial, dated copies of the Indiana Code. Not legal advice; verify at [iga.in.gov](https://iga.in.gov/laws/ic/downloads). [Source](https://github.com/open-indiana-law/indiana-code).
- [Indigo Book MCP](https://indigo.openindianalaw.org): the open Indigo Book manual of legal citation as a searchable tool for AI assistants. A prototype. [Source](https://github.com/open-indiana-law/indigo-book).
- [Judicial education and AI](https://openindianalaw.org/judicial/ai-exploration/): an exploratory project showing how AI can help prepare judicial education, with every limit stated. Released into the public domain (CC0).
